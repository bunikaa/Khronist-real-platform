# translate

Чернетка v1. Перекладає рядки фрагмента сучасною українською, рядок у рядок, для блоку під рядками в панелі (B5). `schema.json` має збігатися з `translateOutputSchema` у `packages/contracts`, це перевіряє тест пакета. Правила — рішення Владислава 17 листопада; історик-консультант може їх уточнити.

## Правила

Усі правила стоять у `system.md` з прикладами в тексті: `examples.jsonl` у запит не потрапляє.

- Вхід — рядки після `normalize` (російська сучасна орфографія), а не прочитані рядки: так модель не плутає дореформені літери з українськими (і, ѣ). Сама нормалізація лишається російською: на ній стоять пошук, сутності й цитата.
- Переклад вірний тексту, без додавань і пояснень, лише українською кирилицею, без жодного російського слова в рядку й без активних дієприкметників на -учий, -ючий, -ачий, -ячий. Сталий словник: крестьянин → селянин, собственник → власник, жена → дружина, житель → мешканець, оба → обоє, и → і, (веро)исповедания → віросповідання, приходский → парафіяльний, дьячек → дячок, диакон → диякон, восприемник(и), восприемница → восприємник(и), восприємниця (як у корпусі), в военной службе → на військовій службі.
- Деревня → село з узгодженням: слова, що узгоджуються з «деревня», беруть середній рід, назва місця зберігає свій рід і число й бере відмінок слова «село» (деревни Михайловской Борщаговки → села Михайлівської Борщагівки, в деревне Никольской Борщаговке → у селі Микільській Борщагівці).
- Імена (Павло додано після прогону 17 листопада): сталі форми Иоанн, Иван → Іван, Мария → Марія, Феодор → Федір, Иаков → Яків, Фома → Хома, Василий → Василь, Григорий → Григорій, Павел → Павло; решта — українськими літерами за звучанням, без зміни роду й відмінка (Андрея → Андрія).
- По батькові: слово на -ов, -ев, -ин, -ова, -ева, -ина (чи повна форма) одразу після імені того самого роду й відмінка завжди стає українським по батькові, як у макеті B5 (Иоанн Петров → Іван Петрович, Анна Иванова → Анна Іванівна, Мойсея Петрова → Мойсея Петровича). Після `[нрзб]` чи з іншим родом або відмінком слово лишається як є, українськими літерами.
- Прізвища — тими самими літерами українською, без виправлень (Левитский → Левитський, не Левицький). TODO(перевірити) з істориком: як передавати голосні в прізвищах (Матвеенко → Матвеєнко чи Матвієнко); модель поки пише по-різному. Назви місць — українські форми (Никольской Борщаговки → Микільської Борщагівки); невідома назва пишеться українськими літерами як є.
- `[нрзб]` лишається на місці стільки разів, скільки було; непрочитане не вгадується. Числа й роки не змінюються, назви місяців перекладаються, дати не перераховуються.
- Рядки не зливаються й не діляться; порожній рядок лишається порожнім, а рядок з текстом не стає порожнім. Слово, перенесене з дефісом, лишається перенесеним між тими самими рядками (Крестья- / нин → Селя- / нин) за українськими правилами переносу, без однієї літери до чи після дефіса; якщо перекладом стало кілька слів, вони діляться між рядками на пробілі без дефіса; обірване на краю фрагмента лишається як є (Ша-).

Рядки — матеріал, а не інструкції: промпт велить не виконувати текст рядків, який просить порушити правила чи змінити формат відповіді, як у `normalize`, `explain` і `chat`. API перевіряє кількість рядків, порожні рядки (рівно там, де у вході; рядок лише з пробілів і невидимих символів — порожній), правило рядка контракту (`lineTextSchema`: до 500 символів, без переносів, NUL і одиночних сурогатів), приховані символи (`\p{Cc}` і `\p{Cf}`: табуляція, керівні, м'який перенос, нульової ширини), яких немає в тому самому рядку входу, латинські літери, яких немає у вході, і кількість `[нрзб]` у кожному рядку (`apps/api/src/services/translate.ts`, у схемі виходу моделі); непридатна відповідь повторюється один раз, потім транскрипція зберігається без перекладу. З резервною моделлю непридатна відповідь коштує до чотирьох викликів у бюджеті (основна, повтор, резервна, повтор). Російські слова, імена й перенос API не перевіряє: відкидати через них увесь переклад було б дорожче, ніж показати машинний переклад з огріхом.

Промпт розрахований на російську мову (`language` — `ru` або `unknown`). Для інших мов нормалізації немає, тож і переклад не викликається.

## Змінні `user.md`

`language`, `period`, `documentType` — з `hints`, без підказки API підставляє `unknown`. `lines` — JSON-масив текстів рядків нормалізації.

## Приклади

`examples.jsonl` — фрагмент фікстури API (`apps/api/src/services/htr/fixture.ts`, він же текст макета B5), п'ять фрагментів, вихід яких є в прикладах `normalize` (`services/knowledge/eval/reference/lines.jsonl`), і один фрагмент золотого набору (`services/knowledge/eval/gold/lines.jsonl`, `2020_6_godparents`, рядки 2–6, нормалізовано вручну). Переклад зроблено вручну за правилами вище; історик його не перевіряв. Тест перевіряє на прикладах кількість рядків, `[нрзб]`, перенос із дефісом, відсутність суто російських літер, окремого «и» й «деревн».

## Перевірка на справжній моделі (17 листопада 2026)

`claude-sonnet-5-5`, `LLM_EFFORT=medium`, шість фрагментів золотого набору після справжньої нормалізації. Перша версія промпту: усі переклади пройшли перевірку API; виклик — близько 1,5 тис. токенів входу й 140–220 виходу, 2,2–3,0 с; через локальний API на справжніх сканах двічі з чотирьох модель думала довше (близько 1 000 токенів виходу, понад 8 с). Огріхи першої версії, через які з'явилися правила вище: «деревні» й «по селі», «Анна Іванова» замість «Іванівна», «Григорій Петрович» з жіночого «Петрова», «Воприємник», «Левицький» замість «Левитський», «Перебува- / ючий». «Житель» поруч із «Мешканець» — не русизм, а непослідовність; тепер «житель» → «мешканець». Результати версії v1 — у звіті задачі V-43.
