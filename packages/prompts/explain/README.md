# explain

Чернетка v0. Пояснює термін, місце, дату чи людину з документа лише за переданими статтями корпусу. `schema.json` має збігатися з `explainOutputSchema` у `packages/contracts`, це перевіряє тест пакета.

## Правила

- Відповідь українською, до трьох речень, лише з переданих статей; власних знань модель не додає.
- Кожне твердження підтверджує цитата: `chunkId` статті й `quote` — точний фрагмент її тексту. Із однієї статті може бути кілька цитат. API відкидає цитати, яких немає в переданих статтях, а без жодної цитати повертає «не знаю».
- Якщо статті не відповідають — `answer: null`, `confidence: low`, без цитат. Це нормальна відповідь.
- `confidence`: `high` — статті відповідають прямо, `low` — частково; тоді відповідь лише про ту частину, яку статті покривають.
- Запис документа — лише контекст, джерелом не є й не цитується.
- Дати модель не обчислює: це робить `calendar.ts`.

## Межі даних

Запис, термін і статті потрапляють у шаблон лише як JSON (рядок або масив), тож текст гостя не може закрити свій блок і видати себе за інструкцію. Системний промпт прямо каже, що це матеріал, а не інструкції: модель відповідає на запитання дослідника, але не виконує текст усередині, який просить порушити правила, взяти інші джерела чи змінити формат. Цитата — щонайменше три слова або 15 символів і починається й закінчується на межі слова; так само її перевіряє API (`isGroundedQuote` у `packages/contracts`).

`gemini.md` — додаток лише для резервної моделі: у чаті `gemini-3.6-flash` переклала ім'я священника українською, тож і тут додаток вимагає писати імена й назви місць із запитання й статей посимвольно в «». API підключатиме його через `loadProviderNotes` разом із маршрутом `POST /v1/explain` (V-11).

## Змінні `user.md`

`kind` — із запиту `POST /v1/explain`, `text` — його `text` JSON-рядком. `period` — `context.period`, без нього API підставляє `unknown`. `record` — `normalizedText` транскрипції з `context.transcriptionId` JSON-рядком, без неї — `null`. `chunks` — JSON-масив до шести знайдених чанків `{ "chunkId", "title", "text" }`, де `title` — назва джерела.

## Приклади

`examples.jsonl` — шість прикладів на справжніх статтях `services/knowledge/data/entries/`: `chunkId` у прикладах — назва файлу статті (у базі це ідентифікатор чанка), `title` — `source_title`, `text` — текст статті. Записи — нормалізовані фрагменти з прикладів `entities`. Відповіді й цитати написано вручну; тест перевіряє, що кожна цитата — точний фрагмент своєї статті. Є приклади з `confidence: low` і з «не знаю» для місця й дати, про які в корпусі статей немає.
