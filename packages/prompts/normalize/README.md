# normalize

Чернетка v0. Переписує прочитані рядки сучасною орфографією тієї самої мови, без перекладу. Контракт — `docs/plan/07-contracts.md`, розділ 8; `schema.json` має збігатися з `normalizeOutputSchema` у `packages/contracts`, це перевіряє тест пакета.

## Правила

Лише правила реформи орфографії 1918 року за статтею «Реформа русской орфографии 1918 года» у російській Вікіпедії (https://ru.wikipedia.org/wiki/Реформа_русской_орфографии_1918_года): ѣ → е, ѳ → ф, і → и, кінцевий ъ відкидається, розділовий ъ лишається, префікси на з/с, закінчення -аго, -яго, -ыя, -ія, форми онѣ, однѣ, ея. Про ѵ декрет нічого не каже; за тією самою статтею на практиці її після реформи не вживали, тому промпт пише и.

Імена, по батькові, прізвища й назви місць змінюються лише за цими правилами для літер і не замінюються іншими формами. Українські форми імен і сіл дають сутності та словник варіантів, а не нормалізація.

Скорочення модель розкриває на власний розсуд, лише загальновідомі, і записує в `expansions`. Перевіреного списку скорочень метричних книг ще немає; коли він з'явиться в корпусі (статті `type: abbr`), його варто додати в промпт.

Промпт розрахований на російську мову (`language` — `ru` або `unknown`). Для інших мов API не повинно його викликати: рядки лишаються без змін, і блок «Сучасною орфографією» в панелі не показується.

## Змінні `user.md`

`language`, `period`, `documentType` — з `hints`, без підказки API підставляє `unknown`, як для `htr_vision`. `lines` — JSON-масив прочитаних рядків у формі `{ "text", "words": [{ "text", "uncertain" }] }`.

## Приклади

`examples.jsonl` — шість фрагментів із `services/knowledge/eval/reference/lines.jsonl`: `source` — фрагмент і номери рядків, `input` — підказки й рядки (непевні — слова з поля `doubt` еталона і `[нрзб]`), `output` — очікуваний вихід. Вихід переписано вручну за правилами вище. Еталонне читання зробила модель, людина його не перевіряла, тому приклади показують правила нормалізації, а не точність читання. Скорочень у цих фрагментах немає, тож `expansions` у прикладах порожні.
