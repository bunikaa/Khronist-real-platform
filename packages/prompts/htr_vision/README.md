# htr_vision

Чернетка v1 під `claude-sonnet-5-5`. Промпт написано без золотого набору, його доводить ML-команда. `examples.jsonl` ще немає: приклади потребують транскрипції історика.

Список формул у `system.md` складено з типової лексики метричних книг і зразків демо-фонду, історик його ще не перевіряв. Він покращує читання формул, але може підштовхувати модель до підстановки: перевіряти це на золотому наборі окремо.

Зображення: фрагмент PNG, вирізаний користувачем, 10–15 рядків, ширина 1200–1600 px. Змінні `user.md`: `language`, `period`, `documentType` з `hints`; якщо підказки немає, API підставляє `unknown`.

`schema.json` має збігатися з `htrVisionOutputSchema` у `packages/contracts`: це перевіряє тест пакета.
