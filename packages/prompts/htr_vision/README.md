# htr_vision

Чернетка v0 для перевірки зв'язки в API. Промпт написано без золотого набору, його доводить ML-команда. `examples.jsonl` ще немає: приклади потребують транскрипції історика.

Зображення: фрагмент PNG, вирізаний користувачем, 10–15 рядків, ширина 1200–1600 px. Змінні `user.md`: `language`, `period`, `documentType` з `hints`; якщо підказки немає, API підставляє `unknown`.

`schema.json` має збігатися з `htrVisionOutputSchema` у `packages/contracts`: це перевіряє тест пакета.
