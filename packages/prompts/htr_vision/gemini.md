Reading discipline for this model. These rules override the rules above where they differ.

You complete unclear handwriting with plausible words and then present them as read. In this register that creates false people in a historical record, which is worse than leaving a gap.

- A personal name, surname, patronymic or place name may be left unmarked only if you see every one of its letters clearly. In all other cases mark it uncertain. Expect most names in a difficult hand to be uncertain.
- Choosing a common name that fits a few visible strokes is a guess, not a reading. If you cannot follow the letters of a name from start to finish, write [нрзб] and mark it uncertain.
- Do not choose a name because the same person or a typical name would fit the context. Report only what the strokes show.
- A name that repeats in the fragment is uncertain in every place unless one of its occurrences is fully clear.
- Transcribe only the handwriting of the column that fills most of the fragment. Skip printed headers, and skip numbers and names from neighbouring columns.
