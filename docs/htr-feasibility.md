# Тест здійсненності читання

Початок тесту, 1 листопада 2026. Це один фрагмент і одна модель; на гейт 0 (вечір 4.11) потрібні 10 аркушів і порівняння Claude та Gemini.

## Зразок 1

- Скан: ЦДІАК, ф. 127, оп. 1078, спр. 177 (1896 р., Борщагівка), зображення 4, розворот «Метрической книги … часть первая, о рождившихся». Файл `/static/files/283/2834611.jpg`, 3000×2481.
- Модель: `claude-sonnet-5-5` через Messages API, цілий розворот одним зображенням, 4969 вхідних токенів.
- Завдання: транскрибувати ліву сторінку, колонку «Званіе, имя, отчество и фамилія родителей», рядок за рядком, JSON, непевні слова позначати.
- Результат: HTTP 200 за 16,3 с. Відповідь обрізана на ліміті 2000 вихідних токенів (з них 679 пішли на міркування), тож повного результату немає.

### Що вдалося
- Модель відокремила записи по рядках, зберегла дореформену орфографію (ъ, і, Ө), коректно прочитала повторювані формули («Священникъ Іоаннъ Бортновскій», «Пономарь Өеодотъ Левитскій», «оба православные», «Крестьянинъ Собственникъ», «Житель Деревни … Борщаговки»).
- Нечитані місця позначені `[нрзб]`, непевні слова винесені окремо.

### Що не вдалося
- Верхня частина прочитана краще, нижня (пошкоджений папір, зшивка) — здебільшого `[нрзб]`.
- Частину імен і топонімів модель явно вгадала (наприклад «Илинецъ», «Манилов-скій»); перевірити без еталона від історика не можна. **CER не виміряно**, золотого набору ще немає.
- 16 с на цілий розворот із міркуванням не вкладаються в ціль 8–10 с на фрагмент у 10–15 рядків.

### Висновки для плану
- Читати треба не цілий розворот, а вирізаний користувачем фрагмент по одній сторінці або колонці; це якраз сценарій виділення області.
- Для структурованого виходу залишити запас вихідних токенів, а міркування (thinking) вимкнути або обмежити, щоб вкластися в час.
- Записи — таблиця з багаторядковими клітинками, а не суцільний текст: промпт `htr_vision` має це знати, а на екрані «рядок» часто означає фрагмент запису.
- Висновок за гейтом 0: «частково читається» для частини сторінок. Для рішення потрібні 10 аркушів, золотий набір і порівняння з Gemini.
