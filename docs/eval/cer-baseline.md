# Базова оцінка читання

14 листопада 2026 року. Повний звіт — `services/knowledge/eval/results/2026-11-14-htr.md`, як відтворити — `services/knowledge/README.md`, розділ «Оцінка читання».

## Набір

- 6 фрагментів метричних книг демо-фонду: ЦДІАК України, ф. 127, оп. 1078, спр. 177, 1954, 2020, 2175, 2276; 1884–1905 рр. П'ять фрагментів — колонка батьків, один — колонка восприемників.
- 67 рядків, 1987 символів, у 55 рядках є імена чи назви місць; в еталоні 34 `[нрзб]`.
- Еталон — читання `claude-opus-5-5`, людиною не перевірене (`services/knowledge/eval/reference/README.md`).
- Читання — тим самим кодом, що й прод, без підказок `hints`, як надсилає розширення.

## Результат

| | `claude-sonnet-5-5` (основна, effort medium) | `gemini-3.6-flash` (резерв, thinking low) |
| --- | --- | --- |
| CER strict | 22,4 % | 21,8 % |
| CER norm (ѣ→е, і→и, ѳ→ф, ѵ→и, без кінцевого ъ) | 22,3 % | 21,8 % |
| WER | 47,1 % | 44,3 % |
| CER на іменах | 22,0 % | 18,5 % |
| Слів позначено непевними | 66,7 % | 47,5 % |
| Частка помилкових слів, позначених непевними | 92,8 % | 68,9 % |
| Частка позначок, що припали на помилку | 61,3 % | 60,3 % |
| Час на фрагмент, с (середній / найбільший) | 7,0 / 8,6 | 27,8 / 51,9 |

За фрагментами CER strict основної моделі — від 7,3 % (1905 р.) до 41,5 % (спр. 2175, 1897 р.).

## Що з цього випливає

- Основна модель лишається `claude-sonnet-5-5`: якість близька до резерву, час укладається в 10 с.
- Резерв у чотири рази повільніший за ціль; він потрібен лише при збої основної моделі.
- Позначки непевності основної моделі ловлять 93 % помилкових слів, але 39 % позначок — зайві (ціль плану: не менше 70 % і не більше 30 %).
- Основна модель у 8 місцях пише «Ө» (U+04E8) замість фіти «Ѳ» (U+0472), тож такі слова не знаходяться пошуком; виправлення — окремим PR.
- Де еталон має `[нрзб]`, а модель прочитала слово, це рахується як помилка, тому цифри радше завищені.
