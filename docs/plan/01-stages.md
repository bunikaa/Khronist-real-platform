## Ритм роботи

- Короткий синк на початку робочого вікна (15 хв, текстом або голосом), один трекер задач (GitHub Projects), демо поточної версії одне одному щовечора.
- Рішення фіксуються текстом у `docs/decisions.md` того ж дня, зокрема будь-яке скорочення обсягу.
- Кожен PR — одна задача, зелений CI, опис «що і навіщо», скріншот для UI. Автор зливає сам після перевірки CI; рев'ю між зонами (В ↔ ML) — лише для змін контрактів.
- Feature freeze 19 листопада ввечері: після нього тільки виправлення дефектів і тексти.
