# 05 · ML, частина 2: довідковий корпус, словник варіантів, промпти

Відповідальні: Анна Бондаренко, Катерина Мех. Код у `services/knowledge`, промпти — у `packages/prompts` (їх читає API Владислава, тому формат файлів фіксований, див. розділ 5).

## 1. Задача

Компаньйон має пояснювати терміни, скорочення, топоніми й дати, відповідати на запитання і при цьому ніколи не вигадувати. Для цього потрібні три речі: довідковий корпус із ліцензіями, пошук по ньому (повнотекстовий, із словником варіантів написання) і промпти, які змушують модель відповідати лише з наданих фрагментів і цитувати їх. Ембедингів у MVP немає: на 100–200 статтях лексичний пошук із варіантами написання працює не гірше і не потребує окремої моделі.

## 2. Стек

| Частина | Вибір | Примітка |
| --- | --- | --- |
| Мова | Python 3.12, uv | скрипти інгестії та оцінки |
| Збереження | PostgreSQL через API ядра: `POST /v1/admin/sources`, `/v1/admin/chunks`, `/v1/admin/synonyms` з API-ключем адміністратора | локально можна напряму через `psycopg`; у проді — через API |
| LLM для тестів промптів | anthropic, google-genai | ті самі моделі, що в API |
| Оцінка | `eval/qa.jsonl`, `eval/run_qa.py` | частка відповідей із коректними посиланнями, частка правильних «не знаю» |

## 3. Довідковий корпус v0 (100 статей до 10 листопада, 150–200 до 15-го)

Пріоритет для метричних книг XIX – початку XX ст.:

1. **Терміни метричних книг**: восприємники, законна жена, оба православнаго исповѣданія, первымъ бракомъ, незаконнорожденный, крестьянинъ, мѣщанинъ, однодворецъ, казакъ, духовный, діаконъ, причетникъ, таинство крещенія, исповѣдь, причастіе, поручители, умеръ отъ…, погребенъ… Кожна стаття: термін, варіанти написання, сучасний відповідник, визначення 2–4 речення, джерело з URL і ліцензією, період.
2. **Скорочення і титла**: типові скорочення в метриках і сповідних розписах.
3. **Календар**: правила юліанського й григоріанського календарів (різниця 12 днів у XIX ст., 13 — з 1900), церковні свята для датування, літочислення «від створення світу». Обчислення робить код Владислава; корпус дає пояснення для користувача.
4. **Топоніми демо-повіту**: 50–100 населених пунктів з історичними назвами, сучасним районом і `wikidata_id` — вивантаження з Wikidata через SPARQL у статті типу `place`. Карта — після фіналу.
5. **Одиниці й гроші**: десятина, верста, сажень, рубль/копійка — коротко.
6. **Джерела з ліцензією**: Вікіпедія й Вікісловник (CC BY-SA, вказувати в `licence`), Енциклопедія історії України (лише цитати з посиланням), відкриті словники староукраїнської мови, публікації істориків (лише короткі цитати з посиланням).

Формат статті — `services/knowledge/data/entries/*.md` з YAML-шапкою:

```yaml
---
term: восприємники
variants: [восприемники, воспріемники, воспріємники, хрещені батьки, кумы]
type: term
period: XVIII–XX
source_title: Енциклопедія історії України, т. 2
source_url: https://…
source_kind: encyclopedia
licence: цитата з посиланням
---
Хрещені батьки, записані в метричній книзі при хрещенні. …
```

`ingest.py` читає теку, кожну статтю кладе як один чанк (статті короткі; довші за 1 500 символів ріже на 2–3 з перекриттям), `variants` пише в `synonyms`, ідентифікує чанк ключем статті (назва файлу) і номером, відправляє через `/v1/admin/*` повним набором (`07-contracts.md`, розділ 2). Повторний запуск оновлює змінені статті, видаляє зниклі й не чіпає інші.

## 4. Словник варіантів написання

Таблиця `synonyms(term, variant, type)` заповнюється з `variants` статей і окремим файлом `data/synonyms.yaml` для імен і топонімів: `Іоаннъ: [Иоанн, Іван, Иван, Іоан]`, `Борщаговка: [Борщагівка, Борщаговка, Борщагувка]`. Нею розширюється запит у `retrieval.ts` і в пошуку Commons. Мінімум до 12 листопада: 100 термінів з варіантами, 50 імен, топоніми демо-повіту.

## 5. Пошук (retrieval)

Реалізує Владислав у `apps/api/src/services/retrieval.ts`; ML-команда задає поріг і перевіряє якість:

1. Запит → розширення варіантами зі `synonyms` → `websearch_to_tsquery('simple', …)` по `chunks.tsv`, `ts_rank`.
2. Паралельно `similarity()` (`pg_trgm`) по `chunks.text` для написань, яких немає у словнику.
3. Злиття, top-6 у промпт. Фільтри: `type` для топонімів і дат; століття запиту в межах `periodFrom`…`periodTo` чанка або період не вказано.
4. Поріг `RETRIEVAL_MIN_RANK`: нижче — «не знаю» без виклику LLM для «Пояснити» й чату без запису; чат із записом викликає модель і з нулем чанків, а відповідь без джерела відсіює перевірка цитат. Стартово 0,05; ML-команда підбирає на `eval/qa.jsonl` і фіксує в `docs/decisions.md`.

## 6. Промпти (`packages/prompts`)

Формат, який читає API: тека на промпт з файлами `system.md`, `user.md` (шаблон з `{{змінними}}`), `schema.json` (JSON Schema виходу), `examples.jsonl` (вхід → очікуваний вихід, 5–10 штук), `README.md`. Зміни промптів — звичайні PR; API підхоплює їх під час збірки.

| Промпт | Вхід | Вихід (structured) | Ключові правила |
| --- | --- | --- | --- |
| `htr_vision` | зображення фрагмента, `hints` | `lines: [{text, words: [{text, uncertain}]}]`, `warnings` | див. `04`, розділ 4, крок 2 |
| `normalize` | рядки з позначками непевності, тип документа, період | `lines: [{text, words: [{text, uncertain}]}]`, `expansions: [{from, to}]` (`07`, розділ 8) | зберігати порядок рядків; не додавати фактів; скорочення розкривати лише загальновідомі; старі літери передавати сучасними за правилами з README |
| `entities` | нормалізований текст і `hints` | `entities: [{type, text, normalized}]`, зміщення рахує API (`07`, розділ 9) | дати лише як знайдені рядки, без обчислень; топоніми — з варіантами для словника |
| `explain` | термін або сутність, контекст запису, top-6 чанків з ідентифікаторами | `answer`, `citations: [chunkId]`, `confidence` | відповідати лише з чанків; кожне твердження має посилання; якщо чанки не відповідають — `answer: null` |
| `chat` | історія діалогу, контекст аркуша, top-6 чанків | `answer` з маркерами `[1]`, `citations`, `followups` | ті самі правила; «не знаю» — нормальна відповідь; не вигадувати дати й особи |

Усі системні промпти починаються зі спільного блоку `packages/prompts/_shared/persona.md`: хто такий Хроніст, що він працює з архівними документами української історії, відрізняє прочитане від інтерпретації, відповідає українською, не вигадує.

## 7. Оцінка

- `eval/qa.jsonl`: 30 запитань — 20 із відповіддю в корпусі, 10 без (очікується «не знаю»).
- `run_qa.py`: для кожного запитання викликає `POST /v1/explain` або `/v1/chat` на локальному API (або retrieval + промпт напряму), перевіряє: чи всі `citations` існують і релевантні (ручна розмітка в файлі), чи немає відповіді там, де корпус порожній. Звіт у `eval/results/`.
- Цільові значення до 17 листопада: 0 відповідей без джерела; не менше 80 % правильних «не знаю».

## 9. Що віддати команді

- `sources`, `chunks`, `synonyms` заповнені в проді; інгестія запускається однією командою.
- `packages/prompts` з п'ятьма промптами, схемами й прикладами.
- Звіти оцінки з датами в `eval/results/`.
- Поріг пошуку — у `docs/decisions.md`.
