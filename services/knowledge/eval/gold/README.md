# Золотий набір

Ті самі шість фрагментів метричних книг, що й в `eval/reference` (ЦДІАК України, ф. 127, оп. 1078, спр. 177, 1954, 2020, 2175, 2276; 1884–1905 рр.): 67 рядків, з них 58 з іменами чи назвами місць. Адреси сканів і рамки фрагментів — у `../reference/fragments.jsonl`.

## Походження

Фрагменти прочитав історик-консультант з нуля, не бачивши читання моделей і `../reference/lines.jsonl`. Транскрипцію отримано 15 листопада 2026 року таблицею; у `lines.jsonl` її перенесено без змін тексту. Тому метрика за цим набором — CER щодо людського читання, а не розбіжність з іншою моделлю.

## Формат `lines.jsonl`

Як у `../reference/lines.jsonl`: `fragment`, `idx` (від 0; історик нумерував рядки від 1), `text`, `names`, `doubt`. Додатково `note` — примітка історика до рядка: можливі інші читання, стан паперу, обрізані краї. Метрики `note` не читають.

`names` і `doubt` — окремі слова з `text`, а не словосполучення: «Старыхъ Безрадичъ» записано двома словами. Розділовий знак, що стоїть при імені в тексті, лишається при ньому («Петрова.»), бо CER імен порівнює слова тексту з `names` дослівно.

## Оцінка

Без `--reference-reader`, бо еталон прочитала людина:

```sh
uv run python eval/run_htr_eval.py --reference eval/gold/lines.jsonl \
  --readings <readings.jsonl> ... --out eval/results/<дата>-htr.md
```
